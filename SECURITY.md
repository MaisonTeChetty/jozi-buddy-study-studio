# Security information

Jozi Buddy is a local Windows portfolio project. It has not undergone an independent penetration test and is not intended for public hosting in this release.

- [Threat model, controls, limitations, and data flow](docs/SECURITY.md)
- [Observed verification results](docs/VERIFICATION.md)
- [Safe demonstration instructions](docs/DEMO.md)

For a security issue, use a synthetic reproduction. Never include AWS credentials, session cookies, passwords, recovery codes, real documents, or private answers in public issues or screenshots. If the repository offers GitHub's private vulnerability reporting, use that channel for details that could expose a user.
